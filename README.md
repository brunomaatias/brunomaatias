## 📌 Projetos em Destaque

### 🏥 Sistema de Vigilância Sanitária Digital
Plataforma web e mobile desenvolvida de ponta a ponta para eliminar o uso de papel nas fiscalizações municipais.
* **Impacto:** Redução do tempo médio de execução das fiscalizações de **40 para 10 minutos**, automatizando a emissão de alvarás, autos de infração e consultas cadastrais via integração com a API da Receita Federal.
* **Stack:** `Java` `Spring Boot` `React` `TypeScript` `PostgreSQL` `JWT`

### 🚓 Plataforma Operacional — Guarda Civil Municipal
Sistema integrado de monitoramento e inteligência geográfica para segurança pública e gestão de eventos.
* **Destaques:** Streaming de câmeras de vídeo IP em tempo real via back-end Spring Boot, mapa interativo da cidade com mapeamento de zonas sensíveis, gestão de equipes e relatórios estatísticos de ocorrências.
* **Stack:** `React` `TypeScript` `Spring Boot` `PostgreSQL` `Leaflet`

### ⚙️ Plataforma de Gestão de Serviços de Campo *(Field Service Management)*
Arquitetura distribuída baseada em **Event-Driven Design** para gestão de ordens de serviço de alta resiliência.
* **Arquitetura:** Microsserviços com Spring Boot/Cloud, API Gateway, Service Discovery (Eureka) e mensageria assíncrona com **RabbitMQ**.
* **Dados & Qualidade:** Persistência poliglota (**PostgreSQL** + **MongoDB**), versionamento de schema com **Flyway**, observabilidade via Actuator, testes com JUnit e esteira CI/CD no GitHub Actions.
* **Stack:** `Java 21` `Spring Cloud` `RabbitMQ` `PostgreSQL` `MongoDB` `Docker Compose` `GitHub Actions`
* 🔗 *[Acessar Repositório](https://github.com/brunomaatias/field-service-management)*
